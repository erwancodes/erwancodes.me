# Erwan Codes' Personal Website

This is the source code for my personal website, built with [Astro](https://astro.build) and deployed on [Vercel](https://vercel.com).

## About

I'm **Erwan Codes**, a computer science student and aspiring software engineer, passionate about technology, artificial intelligence, and digital product creation.

This website serves as my **personal portfolio and blog**, where I share my projects, experiments, and thoughts around web development, AI, and the future of tech.

## Project Structure

```text
├── public/               # Static assets (images, fonts, favicon)
│   ├── assets/          # Images for blog posts
│   └── fonts/           # Web fonts
├── src/
│   ├── assets/          # Icons and images used in components
│   ├── components/      # Reusable UI components
│   │   └── ui/          # UI components
│   ├── content/         # Content collections
│   │   └── blog/        # Blog posts in Markdown format
│   ├── layouts/         # Page layouts and templates
│   ├── pages/           # Routes and pages
│   ├── styles/          # Global styles and CSS
│   └── utils/           # Utility functions
├── astro.config.mjs     # Astro configuration
├── vercel.json          # Vercel deployment configuration
├── package.json         # Project dependencies and scripts
